{# TikZ figure rendered client-side by TikZJax (vendored in static/tikzjax/). Usage in a post: {% tikz(fig_w="520px") %} \begin{tikzpicture} ... \end{tikzpicture} {% end %} fig_w is optional; it sets the rendered width (--fig-w), matching the ep-presentation deck's .tikz-fig convention. The body passes through raw: Zola does not run markdown over an .html shortcode's body, and `str | safe` prevents Tera from escaping it. Use \usetikzlibrary{...} for extra TikZ libraries (arrows.meta, decorations.markings, ...). #}
